# 상상을 현실로(i2R) 홈페이지 개발 기획서

- 작성일: 2026년 10월 23일
- 버전: v8 (PC 우선·3D 우주 중심으로 전환. v7 문의 방식 확정, 전자책 출판사명 반영. v6 행성·도킹 목록 확정, v5 인트로 파일 위치 반영, v4는 v3 가지치기본입니다)
- 용도: 클로드 코드(Claude Code)가 읽고 개발하는 기준 문서입니다.

## 표시 규칙

| 표시 | 뜻 |
|---|---|
| (확정) | 대표가 직접 정한 내용입니다. 그대로 따릅니다. |
| (제안) | 대표가 아직 고르지 않은 내용입니다. 개발 전 대표 확인이 필요합니다. |
| (미정) | 정하지 않은 내용입니다. 개발하지 않거나 자리만 비워 둡니다. |

## 1. 프로젝트 개요

### 1-1. 목적

- 상상을 현실로의 정체성(Identity)을 보여 줍니다. (확정)
- 문의가 오면 좋지만, 문의를 받는 것 자체가 목적은 아닙니다. (확정)
- 내용은 적게, 인상은 강하게 만듭니다. (확정)

### 1-2. 정체성 문장 (확정)

> 문제를 해결합니다.
> 세상에서 제일 작은 기업의 문제를 나열합니다. 그리고 정의합니다. 그리고 해결합니다.
> Ai 시대의 새로운 문제 해결법을 제시합니다.

| 항목 | 내용 |
|---|---|
| 회사 정의 | 크리에이티브 Ai 테크(Creative Ai Tech) 기업 (확정) |
| 슬로건 | 상상을 현실로 / Imagination to Reality (확정) |
| 세상에서 제일 작은 기업 | 1인 기업 (확정) |
| 핵심어 | 초연결(超連結) (확정) |
| 대상 방문자 | 1인 기업, 작은 기업 (확정). 세부 정의 (미정) |

### 1-3. 범위

| 구분 | 회사 홈페이지 (이번 개발) | 개인 홈페이지 (개발 범위 아님) |
|---|---|---|
| 주소 | imag2real.com | namhee.imag2real.com (건드리지 않음) |
| 역할 | 정체성을 보여 줌 | 글, 생각, 포트폴리오 |

- 글과 텍스트 콘텐츠는 개인 홈페이지 몫입니다. 회사 홈페이지에 넣지 않습니다. (확정)

### 1-4. 기본 정보

| 항목 | 내용 |
|---|---|
| 도메인 | imag2real.com. DNS 레코드는 아직 없음 (확정) |
| 회사 메일 | 현재 hello@framelink.space. imag2real.com 메일은 오픈 때 붙임 (확정) |
| 호스팅 | (미정) |

## 2. 우주 세계관

홈페이지의 행성·도킹 섹션은 아래 개념을 따릅니다.

| 개념 | 정의 |
|---|---|
| 우주(유니버스) | 대표. 한 사람의 삶 전체가 하나의 유니버스 (확정) |
| 행성 | 대표가 만들고 뿌리 내린 것. 여러 개 (확정) |
| 도킹 | 대표와 맞물린 다른 사람의 유니버스. 다른 사람이 시작했거나 언제든 빠질 수 있는 것 (확정) |
| 구분 기준 | "누가 시작했나, 빠질 수 있나" (확정) |
| 사람 = 기업 | 1인 기업으로 보아 사람과 회사를 구분하지 않음 (확정) |

## 4. 섹션별 상세

### 4-1. 인트로

- 클로드가 제작한 히어로 영상(Hero Video) v11을 씁니다. 우주 컨셉, 마지막 장면은 워드마크 imag2REAL + 상상을 현실로입니다. (확정)
- 파일: `assets/i2r_hero_v11.html`. 영상 파일이 아니라 캔버스(Canvas)로 그리는 HTML 애니메이션입니다. 현재 파일은 약 21.8초 길이를 끝없이 반복하도록 만들어져 있습니다.
- 첫 방문 시 자동 재생되는 한 번 보는 오프닝입니다. (확정)
- 영상이 끊기지 않고 홈페이지로 이어지는 느낌을 원합니다. (확정) 영상 마지막 장면을 다음 섹션 배경으로 이어 붙이는 방식 (제안)
- 재방문 시 건너뛰기 (미정)
- 인트로가 끝나면 화면이 바뀌지 않고, 카메라가 뒤로 빠지며 그대로 3D 우주가 드러납니다. (제안)

### 4-2. 정체성

- 1-2의 정체성 문장을 그대로 씁니다. 문구 수정은 대표만 합니다. (확정)

### 4-3. 문제 해결

- 세상에서 제일 작은 기업의 문제를 나열하고, 정의하고, 해결하는 흐름을 보여 줍니다. (확정)
- 나열할 문제 목록 (미정)
- 흩어진 점이 선으로 모이는 표현 (제안)
- 초연결 표현: 따로 보이던 문제들이 이어져 있다는 것을 선이 한 번 "띵" 하고 튕기는 표현으로 보여 줌 (제안)

### 4-4. 행성

- 대표가 만들고 뿌리 내린 것들을 보여 줍니다. (확정)
- 목록 (확정)
  1. 씽크텔러(ThinkTeller) 시스템
  2. 전자책 (출판사 이름: 희망 메신저)
  3. 「세 명의 얼굴 천재들」
- 항목마다 이름, 한 줄 소개, 관련 링크 (제안)

### 4-5. 도킹

- 대표와 맞물린 다른 유니버스를 보여 줍니다. (확정)
- 목록 (확정)
  1. 프레임링크
  2. 아힘사 요가명상 브랜딩
  3. 모마음 요가명상 영상 제작
- 항목마다 이름, 한 줄 소개, 그 사람·기업의 홈페이지 링크 (제안)
- 올리기 전 당사자 동의를 받습니다. (제안)

### 4-6. 맡길 수 있는 일 (확정)

| 서비스 | 내용 | 상태 표시 |
|---|---|---|
| Ai 시스템 세팅 | 개인·기업 맞춤 시스템 세팅. 씽크텔러 시스템 개념, 메모리 최적화 세팅 | 준비 중 |
| 마케팅 제작 | 영상, 홈페이지 등 | 운영 중 |
| 맞춤 교육 솔루션 | 기업별 맞춤 교육 | 운영 중 |

- "준비 중"은 아직 불이 켜지지 않은 별로 표현합니다. (확정)
- 준비 중 서비스의 대기 문의 (제안)
- 서비스별 증거 자료 노출 (미정)

### 4-7. 문의

- 문의는 카카오톡으로 연결합니다. 버튼을 누르면 카카오톡 대화로 이동합니다. (확정)
- 홈페이지 안에 입력 양식은 두지 않습니다. (확정)
- 연결할 카카오톡 주소(채널 또는 오픈채팅) (미정)

### 4-8. 개인 홈페이지 링크

- namhee.imag2real.com으로 이동합니다. (제안)

## 5. 디자인 방향

### 5-1. 분위기

- 우주 컨셉 (확정)

### 5-2. 색상

- 구성: 흰색·검정·회색 + 강조색 노랑 (확정). 기존 검정·아이보리·오렌지는 쓰지 않습니다. (확정)
- 정확한 색상 값은 (미정)입니다. 개발 중에는 아래 값을 임시로 씁니다. (제안)

| 이름 | 역할 | 임시 색상 값 |
|---|---|---|
| 흰색 | 기본색 | #FFFFFF |
| 검정 | 기본색 | #101010 |
| 회색 | 기본색 | #8C8C8C |
| 노랑 | 강조색 | #FFD400 |

- 노랑은 강조에만 씁니다. 쓸 곳 (미정)
- 노랑 바탕에는 검정 글씨를 씁니다. (제안)

### 5-3. 폰트

- 프리텐다드(Pretendard), 대체 폰트 노토 산스 KR(Noto Sans KR) (확정)
- 이탤릭체 사용 금지 (확정)

### 5-4. 로고

- 심볼 로고는 바뀔 예정이므로 현재 시안으로 개발하지 않습니다. (확정)

### 5-5. PC 우선 (확정)

- 보여 주기 위한 홈페이지이므로 PC 화면을 기준으로 만듭니다.
- 3D 우주를 홈페이지의 중심으로 씁니다.
- 모바일은 PC 버전을 그대로 줄이지 않고, 따로 최적화한 버전을 둡니다. 모바일 버전의 형태 (미정)

## 7. 완료 기준 (제안)

| 섹션 | "이게 되면 완성" |
|---|---|
| 인트로 | 첫 방문 시 영상이 재생되고, 끊김이나 깜빡임 없이 본문으로 이어진다 |
| 정체성 | 우주가 드러난 첫 화면에서 정체성 문장이 읽힌다 |
| 문제 해결 | 나열 → 정의 → 해결 순서가 화면에서 보인다 |
| 행성 · 도킹 | 등록된 항목이 모두 보이고 링크가 열린다 |
| 맡길 수 있는 일 | 세 서비스가 보이고, 시스템 세팅에 "준비 중"이 표시된다 |
| 문의 | 문의 버튼을 누르면 카카오톡 대화가 열린다 |
| 공통 | 이탤릭체가 없다. PC에서 버벅임 없이 움직인다. 모바일 버전에서 확대 없이 읽힌다. imag2real.com으로 접속된다 |
