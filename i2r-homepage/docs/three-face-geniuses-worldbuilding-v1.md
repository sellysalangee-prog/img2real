## 2. 캐릭터 프로필

### 2-1. 공통 설정

- 세 사람은 같은 의대 본과 4학년 동기이며 6년 지기입니다.
- 본편에서 세 사람은 이수재 소유의 아파트(병원장 아버지 소유)에서 함께 삽니다.
- 세 사람 모두 머리가 좋습니다. 성적 순위(도혁 1등, 하진 2등, 수재 꼴찌)는 머리 순위가 아니라 각자의 성향과 상황에서 나온 결과입니다.
- 이름은 본편에서 이미 확정되어 있으므로 이름 후보는 제안하지 않습니다.

## 5. 사무실 편 설정

### 5-1. 입사 경위 (제안)

1. 하진이 「상상을 현실로」 홍보 영상의 모델 알바로 먼저 사무실에 옵니다.
2. 촬영 중 남희 대표가 홈페이지 개발을 Ai 셋(클로드·제미나이·GPT)과 함께 하고 있고, 각 Ai를 맡아 줄 담당자가 필요하다는 이야기를 듣습니다.
3. 하진이 도혁과 수재를 데려옵니다. 도혁은 과외보다 시급이 좋아서, 수재는 "이 회사 조건 좋다"는 감으로 들어옵니다.
4. 셋이 같이 사는 집에 고양이 셋만 두고 나올 수 없어서, 대표의 허락을 받아 고양이도 함께 출근합니다.

- 근무 형태 (제안): 실습이 끝난 뒤 저녁과 주말에 출근하는 파트타임입니다.

### 5-2. 대표 남희와의 관계

| 항목 | 정의 |
|---|---|
| 지시 흐름 | 대표 → 수재(팀장) → 하진·도혁. 대표는 수재에게 지시하고, 수재가 일을 나눕니다. |
| 대표의 위치 | 맨 안쪽 큰 책상에 앉아 지시를 내립니다. |
| 세 사람의 태도 (제안) | 대표를 존중합니다. 대표 앞에서는 셋 다 존댓말을 씁니다(도혁은 존댓말도 의학 용어로). |
| 대표가 보는 세 사람 (제안) | 각자 잘하는 게 확실한 팀원입니다. 성적이 아니라 맡은 일로 봅니다. |

### 5-3. 사무실 배치

```
┌──────────────────────────────────────┐
│                                      │
│          [ 대표 책상 — 남희 ]          │  ← 맨 안쪽, 가장 큰 책상
│                                      │
│                                      │
│          [ 팀장 책상 — 수재 ]          │  ← 대표 바로 앞 가운데 (제안)
│                                      │
│                                      │
│  [ 하진 책상 ]            [ 도혁 책상 ]  │  ← 수재 책상 양옆 앞쪽 (제안)
│                                      │
│  (고양이 방석 3개 — 각 책상 옆) (제안)   │
│                                      │
│              [ 출입문 ]               │
└──────────────────────────────────────┘
```

| 책상 | 위치 | 소품 (제안) |
|---|---|---|
| 대표 책상 | 맨 안쪽 중앙, 가장 큼 | 모니터 2대, 결재함 |
| 수재 책상 | 대표 바로 앞 가운데 | 우유 팩, 업무 배분 화이트보드, 클로드(Claude) 명패 |

## 7. 지켜야 할 것

### 7-1. 캐릭터가 절대 하지 않는 행동

| 대상 | 금지 사항 |
|---|---|
| 공통 | 서로를 진짜로 깎아내리거나 따돌리지 않습니다. 티격태격은 놀림까지만 허용합니다. |
| 공통 | 꼴찌·성적을 머리가 나쁜 것으로 표현하지 않습니다(셋 다 똑똑함). |
| 공통 | 대표 지시를 무시하거나 대표를 우습게 보는 행동을 하지 않습니다. |
| 수재 | 일을 나누기만 하고 손 놓는 모습으로 그리지 않습니다. 수재는 직접 개발도 합니다. |
| 하진 | 웃음이 꺼진 차가운 얼굴(본편의 '맹견' 얼굴)을 사무실 편에서 쓰지 않습니다. |
| 도혁 | 이모티콘·감탄사·농담으로 말하지 않습니다. 의학 용어는 실제 지식에 맞게 쓰고, 숫자나 병명을 지어내지 않습니다. |
| 고양이 | 다치거나 떨어지거나 괴롭힘당하는 장면을 넣지 않습니다(제안). |

### 7-2. 사무실 편에 가져오지 않는 본편 설정

- 세 남주의 아버지 관련 설정과 검은 세단
- 하진의 여자친구 관계의 속사정
- 정희수의 유년기와 세 남주의 연애 감정 구도
- 본편의 로맨스 신호(스킨십 농도, 속마음 누출 연출). 사무실 편의 스킨십은 하이파이브·어깨동무 수준까지만 씁니다(제안).

### 7-3. 분위기에 안 맞는 표현

- 피, 수술 장면 등 실제 의료 현장 묘사. 도혁의 의학 용어는 말로만 씁니다("출혈 부위야"는 대사로만, 화면에 피를 그리지 않음).
- 야근 압박, 고성, 혼나는 장면 등 직장 스트레스 연출
- 세 Ai(클로드·제미나이·GPT) 중 어느 쪽이 더 낫다고 비교하거나 깎아내리는 대사(제안). 셋은 각자 맡은 일이 다른 동료로 그립니다.
- 각 Ai 회사의 로고 이미지를 화면에 그대로 쓰는 것(제안). 담당 표시는 명패 글자로만 합니다.
