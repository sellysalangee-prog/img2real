# 코딩 친구 (Vibe Coding Bot)

아이가 로블록스(Roblox) 게임 스크립트를 Claude와 함께 만드는 학습용 웹앱입니다. Anthropic API로 `claude-opus-5-5` 모델을 호출합니다.

## 1. 구성

| 구분 | 내용 |
|---|---|
| 프레임워크 | Next.js 15 (App Router) |
| 저장소 | PostgreSQL (첫 요청 때 테이블 자동 생성) |
| 첨부 파일 | Vercel Blob, 비공개(private) 저장소. 브라우저가 Blob에 직접 올리고, 읽기는 서버만 합니다. |
| Claude 호출 | `@anthropic-ai/sdk`, 서버에서만 호출. API 키는 브라우저로 전달되지 않습니다. |
| 배포 | Vercel 기준 (Root Directory: `vibe-coding-bot`) |

## 2. 환경 변수

| 이름 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키 |
| `ADMIN_PASSWORD` | 관리자 비밀번호. 대소문자를 구분합니다. |
| `SESSION_SECRET` | 32자 이상 무작위 문자열. 로그인 쿠키와 아이 비밀번호 암호화에 사용합니다. 변경하면 저장된 아이 비밀번호를 다시 설정해야 합니다. |
| `DATABASE_URL` | PostgreSQL 연결 주소 (`POSTGRES_URL`도 인식합니다). Neon을 연결할 때 Custom Prefix를 `DATABASE`로 입력하면 이 이름으로 생성됩니다. |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob 저장소 토큰. 첨부 업로드 토큰 발급에 반드시 필요합니다. |

## 3. 처음 사용 순서

1. **Storage → Create Storage**에서 Neon(DB)과 Blob(접근 방식 **Private**)을 각각 만들고 이 프로젝트에만 연결합니다.
   - Neon 연결 시 Custom Prefix: `DATABASE`
   - Blob 연결 시 Custom Prefix: `BLOB`, **Add a read-write token env var to this connection** 체크
   - 연결 후에는 다시 배포해야 환경 변수가 적용됩니다.
2. 나머지 환경 변수를 넣고 배포합니다.
3. 관리자 비밀번호로 로그인합니다.
4. **아이 비밀번호** 탭에서 아이 비밀번호를 정합니다. 정하기 전에는 아이가 로그인할 수 없습니다.
5. **지침** 탭에서 지침을 입력합니다. 지침이 비어 있으면 아이 화면에서 질문을 보낼 수 없습니다.

## 4. 기능 규격

### 4.1 로그인

- 비밀번호 입력란 하나로 로그인합니다. 관리자 비밀번호면 관리자 화면, 아이 비밀번호면 아이 화면으로 이동합니다.
- 관리자 비밀번호: 환경 변수에 보관, 대소문자 구분.
- 아이 비밀번호: DB에 암호화 보관, 대소문자 구분 안 함, 영문·숫자 1~40자. 관리자 비밀번호와 대소문자만 다른 값은 거부합니다.
- 같은 접속 주소(IP)에서 5번 틀리면 5분간 잠깁니다.
- 로그인 유지 기간: 아이 30일, 관리자 1일.

### 4.2 아이 화면 (`/chat`)

| 영역 | 기능 |
|---|---|
| 왼쪽 메뉴 | 새 대화, 지난 대화 목록, 프로젝트 지식 목록. 모바일에서는 ☰ 버튼으로 엽니다. |
| 대화창 | 답이 실시간으로 표시됩니다. 코드 블록마다 **복사** 버튼이 있습니다. |
| 문서 블록 | Claude가 ` ```markdown 파일이름.md ` 블록으로 문서를 쓰면 아래에 **프로젝트에 저장** 버튼이 표시됩니다. 이 형식은 관리자가 지침에 적어 두어야 합니다. 이름을 확인·수정한 뒤 저장합니다. |
| 첨부 | 사진(png, jpg, gif, webp) 5MB, PDF 20MB, 글자 파일(lua, txt, md, json 등) 1MB까지. 큰 사진은 올리기 전에 긴 변 1568px로 줄입니다. PC에서는 스크린샷 붙여넣기(Ctrl+V)도 됩니다. |
| 프로젝트 지식 | 문서를 누르면 모든 버전을 골라 볼 수 있습니다. 삭제 버튼은 없습니다. |

### 4.3 관리자 화면 (`/admin`)

| 탭 | 기능 |
|---|---|
| 대화 기록 | 아이의 모든 대화를 시간과 함께 열람합니다 (읽기 전용). |
| 지침 | 시스템 프롬프트 입력·저장. 코드에는 기본 지침이 없으며, 입력한 내용은 DB에만 저장됩니다. |
| 프로젝트 지식 | 파일 업로드, 직접 작성, 버전별 열람·삭제. |
| 아이 비밀번호 | 현재 비밀번호 확인, 변경. |

### 4.4 Claude에게 보내는 내용 (매 요청)

`system`에 아래 순서로 들어갑니다.

1. 관리자 지침 (DB의 `settings.system_prompt`)
2. 프로젝트 지식: 문서 이름마다 **가장 새 버전만** `<project_knowledge>` 태그로 감싸 넣습니다. 문서가 없으면 생략합니다. 옛 버전은 화면에서만 볼 수 있습니다.

지침 문구와 아이에 관한 정보는 코드에 두지 않습니다. 모두 관리자 화면에서 입력해 DB에만 저장합니다.

그 뒤에 현재 대화 전체가 `messages`로 들어갑니다.

### 4.5 요청 설정

| 항목 | 값 | 이유 |
|---|---|---|
| 모델 | `claude-opus-5-5` | 요구 사항 |
| effort | `medium` | 모델 기본값. 답 품질이 부족하면 `lib/claude.ts`에서 `high`로 올립니다. |
| 스트리밍 | 사용 | 긴 답이 끊기지 않고 실시간 표시 |
| 프롬프트 캐시 | system 끝 + 대화 끝 | 지침·문서·이전 대화를 다시 읽는 비용 절감 |
| 거절 대체 (`fallbacks: "default"`) | 사용 | 안전 검사로 거절되면 서버가 알맞은 모델로 다시 답합니다. |
| 생각 블록 불일치 (`drop_block`) | 사용 | 대화 도중 지침이나 문서가 바뀌면 예전 생각 블록이 맞지 않게 됩니다. 이때 오류 대신 해당 블록만 빼고 진행합니다. |

답을 받지 못한 질문(거절, 오류)은 표시만 남기고 다음 요청부터 Claude에게 보내지 않습니다.

## 5. 데이터 구조

| 테이블 | 내용 |
|---|---|
| `settings` | 지침, 아이 비밀번호(암호화) |
| `login_attempts` | IP별 실패 횟수, 잠금 시각 |
| `conversations` | 대화 제목, 시각 |
| `messages` | 대화 내용. Claude 응답은 API 블록 그대로 저장. 토큰 사용량(`usage`) 기록 |
| `attachments` | 첨부 파일 정보와 Blob 주소. 파일 원본은 Vercel Blob에 있습니다. |
| `knowledge_docs` | 프로젝트 지식. `(name, version)` 단위로 모든 버전 보관 |

## 6. 이후 확장 지점

| 기능 | 붙일 위치 |
|---|---|
| 기억 저장 | `lib/context.ts`의 `CONTEXT_SOURCES`에 기억 조각을 추가 |
| 관찰 보고서 | `messages` 테이블(시각·내용·사용량)을 읽는 관리자 API 추가 |
| 비용 상한 | `messages.usage` 합계를 `app/api/chat/route.ts`에서 요청 전에 확인 |
| 쇼케이스 화면 | `knowledge_docs`와 대화를 읽는 새 페이지 추가 |

## 7. 로컬 실행

```bash
cd vibe-coding-bot
npm install
DATABASE_URL=postgres://... ADMIN_PASSWORD=... SESSION_SECRET=... ANTHROPIC_API_KEY=... BLOB_READ_WRITE_TOKEN=... npm run dev
```

## 8. 알려진 제한

- 답 하나가 5분(`maxDuration = 300`)을 넘으면 Vercel이 연결을 끊습니다.
- 첨부 사진은 매 요청마다 다시 전송됩니다. 사진이 많은 긴 대화는 새 대화로 시작하는 것이 좋습니다.
- 대화 삭제 기능은 없습니다.
- 첨부를 올린 뒤 보내지 않고 빼거나 화면을 닫으면, 그 파일은 Blob에 남습니다. 자동 정리 기능은 없습니다.
